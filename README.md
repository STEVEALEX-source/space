# space

A personal visual essay of the eight worlds in our solar system.

An interactive 3D experience built with Three.js — soft lighting, procedural planet textures, orbiting moons, asteroid belt, and written reflections for each planet.

## Features

- Cinematic intro screen
- Smooth camera controls (drag to orbit, scroll to zoom)
- Click any planet to open its chapter
- Procedural surface textures for all 8 planets
- Moons with independent orbits
- Saturn’s rings
- Asteroid belt between Mars and Jupiter
- Soft atmospheric glow on Earth & Venus
- Written field notes + data for every planet
